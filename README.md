# Küçük Çiğli Rota Haritası

Katılım35-2 · Atölye 1 – Düşük Karbonlu ve Erişilebilir Ulaşım Atölyesi için tablet haritası.
Başlangıç noktalarından (1 Atasanayi İZBAN, 2 Ata Sanayi tramvay, 3 Turan Çakın İlkokulu) İZSEM'e yürüme rotaları; haritaya dokunulan noktanın Sokak Görünümü sayfa içinde açılır.
